# Skill: Write Changelog

## Goal
Append a properly structured session entry in CHANGELOG.md.

## Procedure
1) Open CHANGELOG.md, create a `[Session-YYYY-MM-DD]` heading.
2) Summarize changes (Features/Bugs/Theme/Perf).
3) Include verification ticks: UI/Backtest/Lint/Build.
4) Save and stage the file.

## Output
- New CHANGELOG entry ready to commit.
